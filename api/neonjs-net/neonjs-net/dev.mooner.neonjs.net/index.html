NetExtension
Link copied to clipboard
class NetExtension @JvmOverloads constructor(val options: NetOptions = NetOptions.DEFAULT) : NeonExtension

fetch and WebSocket for the contexts of an engine, over OkHttp, within options' network policy: NeonEngine.builder().webGlobals(true).extension(NetExtension(NetOptions.builder().allowHosts("api.example.com").build())). Also the modules undici and ws (importable, and requirable with neonjs-node), which give libraries written for those packages the same fetch and WebSocket. Needs the web globals. The engine's contexts share one client (its connection pool); each context has its own limits of fetches and sockets.

NetOptions
Link copied to clipboard
class NetOptions

What the fetch and WebSocket of a context may reach, and how much of the host they may use. Nothing is reachable by default: a host names the hosts its scripts need (Builder.allowHosts). Whatever the hosts, a connection to a loopback, private, link-local or otherwise non-public address is refused unless its range is allowed (Builder.allowAddresses), and so is cleartext (http:, ws:) unless allowed (Builder.allowInsecure).
