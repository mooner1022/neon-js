NodeOptions

class NodeOptions

What the Node.js APIs of a context see of the host. Nothing of the host's own environment shows unless given here: process.env is empty by default, and process.exit never ends the host process.

val consoleInspect: Boolean

Whether console formats as Node's does, with node:util's format and inspect (default: true): objects show as their libraries mean them to ([util.inspect.custom]), which runs guest code while logging. When false, the console keeps the core's formatting, which never runs guest code.
