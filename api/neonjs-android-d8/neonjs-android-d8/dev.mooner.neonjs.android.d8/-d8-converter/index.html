D8Converter

class D8Converter : DexConverter

Translates generated classes with D8, the dexer that replaced dx in the Android SDK (maintained, no Java 8 class file ceiling). D8 is built for whole-program builds: a run has a fixed cost of several milliseconds on a phone, many times dx's, so it suits batches of classes (background compilation) far better than one class at a time; the r8 library adds several megabytes of dex.

Desugaring is off: generated code uses neither lambdas nor Java library APIs that would need it.
