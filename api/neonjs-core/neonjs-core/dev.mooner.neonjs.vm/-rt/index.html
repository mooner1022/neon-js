@JvmStatic
fun attachStack(t: JSException, f: Frame, pc: Int)

Gives an error thrown in frame f at pc its stack trace: errors without one get it now; errors the engine raised in the current step of f (see JSErrorObject.capturedAt) get it again with the exact pc. An error that was created earlier, caught by native code and rethrown later (a rejected promise awaited) keeps its stack.
