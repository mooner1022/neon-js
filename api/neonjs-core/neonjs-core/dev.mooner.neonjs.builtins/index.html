AsyncDisposal

class AsyncDisposal

The DisposeResources loop of an async disposal, suspended at each Await. Protocol: call step; while it returns true, Await awaitValue and on rejection report the reason via rejected (on fulfillment nothing is reported), then call step again. Once step returns false, result is the resulting completion (null for normal).
