DateTime

object DateTime

Time value arithmetic of ECMA-262 §21.4.1 (Day, YearFromTime, MakeDay, TimeClip, ...), the host local time zone (LocalTime / UTC) and the string forms produced by Date.prototype methods.

Time values are Doubles combined exactly as the spec's Number arithmetic. Calendar decompositions work on Long day counts and expect finite arguments; time zone lookups clamp their argument, so intermediate values of any magnitude (before TimeClip) remain computable.
