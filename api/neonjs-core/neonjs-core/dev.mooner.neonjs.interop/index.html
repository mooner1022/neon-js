HostObject
Link copied to clipboard
class HostObject(val bridge: HostBridge, val target: Any, val info: HostClassInfo) : JSObject

Exotic object exposing a host (Java/Kotlin) object's public members as properties: fields, methods, and bean-style properties (getX/isX/setX, i.e. Kotlin properties). Where the policy allows the views (HostClassInfo.arrayLike, HostClassInfo.mapLike, HostClassInfo.iterable), Java arrays and Lists are array-like, Maps expose entries through get/set and Iterables are JS-iterable. Functions (lambdas, @FunctionalInterface and Kotlin function type implementations, see HostClassInfo.findFunctionalMethod) are callable. A signature key such as append(java.lang.String) names one overload (HostClassInfo.overload).
