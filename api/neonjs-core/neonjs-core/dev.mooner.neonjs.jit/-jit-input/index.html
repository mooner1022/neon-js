JitInput

class JitInput(cb: CodeBlock, debugInfo: Boolean = JvmCompiler.DEBUG_INFO, planInlining: Boolean = true, val tierUp: Boolean = false)

Everything the class generated for a code block depends on, and nothing else: JvmCompiler's code generator reads only these fields, so identity, a hash of all of them, decides whether two code blocks can share a class. Constants are not part of it (generated code reads them from the running frame's code block at run time).
