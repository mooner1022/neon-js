Makes code, a later version of cb's code (the optimizing tier's), the code new activations of cb run (docs/OPTIMIZING_TIER.md, "Code versions"). loop

@JvmStatic
fun loop(cb: CodeBlock, agent: Agent): Boolean

An interpreted loop of cb made LOOP_CHECK more iterations. Credits them toward compiling the block (adaptive mode: 64 per period, so a function whose time goes into its loops is compiled after about 64K iterations even when it is called only a few times), and queues the block once due rather than at its next call, so its code is ready while the loop still runs. Returns whether compiled code is installed that the loop can continue in (osr).

osr
Link copied to clipboard
@JvmStatic
fun osr(f: Frame): Any?

On-stack replacement: continues interpreted frame f in its code block's compiled code, at the loop header Frame.pc with the registers in Frame.slots and an empty operand stack (see CompiledCode). Returns the frame's result, or JitRt.NO_OSR (nothing done) when the code has no entry there. Called by the interpreter outside its exception dispatch: exceptions leave the frame as they leave compiled code (JitRt.leaveCompiled).
