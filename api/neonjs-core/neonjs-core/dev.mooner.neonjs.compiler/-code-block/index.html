CodeBlock

class CodeBlock(name: String, val kind: FunctionKind) : CodeUnit

Compiled function template (bytecode + metadata): JavaScript's CodeUnit. What the execution core reads is the unit's (bytecode, constants, handlers, registers, flags, the JIT's state); the rest is JavaScript's. CodeUnit.lineTable holds pairs (pc, source position).

@JvmField
var callFeedback: Array<CallFeedback?>?

Interpreter feedback for the JIT's inlining (dev.mooner.neonjs.jit.Inlining): at the pc of each CALL that called a JS function, the code block called most. Created on the first such call; written without synchronization (a heuristic only: the generated code checks its target at every call).

callHintPcs
Link copied to clipboard
@JvmField
var callHintPcs: IntArray?

Static call targets, for the JIT's inlining where there is no feedback (compiled mode): the pcs of CALLs whose callee is a name that a function declaration, or a var/let/const declaration with a function or arrow, binds, sorted, and the code blocks of those functions (callHintTargets). Written by the compiler once the whole source is compiled. A hint only, as the feedback: the binding may be assigned something else, and the generated code checks its target at every call.
