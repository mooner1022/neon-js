ValueProfile
Link copied to clipboard
class ValueProfile(codeSize: Int, params: Int)

Kinds of the values the interpreter saw a code block produce, for the optimizing tier's speculation (docs/OPTIMIZING_TIER.md, "Feedback"): at the pc of each GET_PROP, GET_ELEM, CALL and LOAD_ENV, and for each formal parameter at entry, a set of kindOf bits. Written without synchronization: a lost bit only means a speculation that fails and deoptimizes.
