LOAD_GLOBAL_LEX
Link copied to clipboard
const val LOAD_GLOBAL_LEX: Int = 1015

(no inputs) a global variable read through the entry its site's cache held (GlobalCache.load): LOAD_GLOBAL_LEX reads a lexical binding, Inst.a indexing the global environment's token in the graph's data and Inst.b being the binding's index; LOAD_GLOBAL_SLOT reads a data property of the global object, Inst.a indexing its shape, Inst.b being the slot and Inst.c the environment's lexical epoch.
