Ir

object Ir

The operations of the IR that every language's graphs have (docs/IR_NEUTRALITY.md): terminators, exception handlers' homes, the records and guards of calls compiled inlined, the stress mode's exits. A language's own operations are its bytecode's (below 1000) and those its builder makes (from 2000: JavaScript's are JsIr).

SUSPEND
Link copied to clipboard
const val SUSPEND: Int = 1106

(value?) leaves the code, its activation suspended (a generator's yield, an async function's await): the interpreter's state at the pc it resumes at (Inst.state) and the value it hands over are written to the frame (the language's suspension, Inst.a its kind), and the code returns the interpreter's SUSPENDED. Its target is the block where the activation resumes (Block.resumeEntry), which the code's entry dispatch enters.
