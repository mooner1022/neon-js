KindSystem

interface KindSystem

A language's kinds of values (docs/IR_NEUTRALITY.md, "KindSystem"): what the optimizing tier knows of a value without a check, as a byte. Every value of the IR has one (Value.kind); Kinds infers them, and the code generator holds each value as its kind's rep.

A kind must say the truth on every path: it comes from what an operation produces by definition or from a check that exits otherwise (a speculation), never from a profile alone.
