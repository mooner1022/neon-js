class Block(var id: Int, val pc: Int, val site: InlineSite? = null)

A basic block: phis, then instructions, the last of which is its terminator (Inst.isTerminator). site is the call compiled inlined whose body it belongs to (null: the function compiled); pc is its first instruction's in that body.

FrameState
Link copied to clipboard
class FrameState(val pc: Int, val values: Array<Value>, val site: InlineSite? = null)

The interpreter's state at an exit (Deopt) in the function compiled (site null) or in the body of a call compiled inlined (site): where it resumes, pc, and the values of the registers then the operand stack there (values). An inlined body's caller has its own state at the call (InlineSite.callerState). Its values, and those of its sites, are uses, as instruction inputs are.

Graph
Link copied to clipboard
class Graph(val code: CodeBlock)

The optimizing tier's intermediate representation (docs/OPTIMIZING_TIER.md, "IR"): a control flow graph of Blocks whose instructions are in SSA form. A Value is defined once: a constant, a parameter, a phi at the start of a block, or an instruction's result.

class InlineSite(val parent: InlineSite?, val code: CodeBlock, val callPc: Int, val callerState: FrameState, var fn: Value, var thisValue: Value, val args: Array<Value>, var env: Value, val construct: Boolean = false)

A call compiled inlined: the callee's code, the CALL at callPc in its caller (the body of parent, or the function compiled), the caller's state at that call (callerState: its registers and the stack below the call's operands), and what a frame of the callee holds: the closure fn, this as the call binds it (thisValue; undefined where the callee does not read it), the arguments, the environment.

class Inst(var op: Int, var inputs: Array<Value>, val a: Int, val b: Int, val c: Int, val pc: Int, val stmt: Int) : Value

An instruction. op is a bytecode instruction (Op) with its own semantics, its stack operands being inputs in stack order and its result (if it pushes one) this value, or one of the Ir operations. a, b and c are its operands as in the bytecode; pc its position, stmt that of the statement it belongs to (stack traces).

object IrVerifier

Checks the invariants the passes and the code generator rely on: every block ends with its one terminator, its predecessors are the blocks whose terminators target it (as often as they do), every phi has an input per predecessor, and every value is defined before its uses on every path (SSA dominance).

T2Code
Link copied to clipboard
abstract class T2Code(val data: Array<Any?>, val block: CodeBlock) : CompiledCode

The superclass of the optimizing tier's classes: the code of one block (block) with what it was compiled against (data: objects the code compares with or reads, which a class cannot hold as constants), and the count of its deoptimizations. Code that deoptimizes too often gives way to the baseline for good (exit).
