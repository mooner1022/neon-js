OpInfo

open class OpInfo(val name: String, val flags: Int, val hoist: Int = HOIST_NEVER)

What the optimizing tier's passes know of an operation (docs/IR_NEUTRALITY.md, "OpInfo"): its effects as flags, and how loop-invariant code motion may move it. A language's operations come from its OpTable; the passes ask these questions of the table and list no operations of their own.

The flags say what an operation may do. An exit (leaving for the interpreter where a speculation fails) is none of them: it is the instruction's state (Inst.state), which every pass keeps.
