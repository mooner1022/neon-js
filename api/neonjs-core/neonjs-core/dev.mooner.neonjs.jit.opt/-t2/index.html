T2

object T2

The optimizing tier's compiler (docs/OPTIMIZING_TIER.md): a code block's Graph, then its class, defined by the same CodeDefiner as the baseline's. One class per compiled block: its code is the block's own, never shared.

MAX_CODE
Link copied to clipboard
@JvmField
val MAX_CODE: Int

The most bytes of JVM code the tier's run may have (-Dneonjs.jit.t2MaxCode). HotSpot does not compile a method of more than 8,000 (-XX:+DontCompileHugeMethods, the default), and ART not one of more than 10,000 dex code units, which such a method stays under once translated (dx optimizes large classes, D8 all). Code past that would run in the JVM's bytecode interpreter, far slower than the baseline's compiled code: the block keeps its baseline.
