Graph

class Graph(val code: CodeBlock)

The optimizing tier's intermediate representation (docs/OPTIMIZING_TIER.md, "IR"): a control flow graph of Blocks whose instructions are in SSA form. A Value is defined once: a constant, a parameter, a phi at the start of a block, or an instruction's result.
