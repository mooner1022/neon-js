T2Code

abstract class T2Code(val data: Array<Any?>, val block: CodeBlock) : CompiledCode

The superclass of the optimizing tier's classes: the code of one block (block) with what it was compiled against (data: objects the code compares with or reads, which a class cannot hold as constants), and the count of its deoptimizations. Code that deoptimizes too often gives way to the baseline for good (exit).
