InlineSite

class InlineSite(val parent: InlineSite?, val code: CodeBlock, val callPc: Int, val callerState: FrameState, var fn: Value, var thisValue: Value, val args: Array<Value>, var env: Value, val construct: Boolean = false)

A call compiled inlined: the callee's code, the CALL at callPc in its caller (the body of parent, or the function compiled), the caller's state at that call (callerState: its registers and the stack below the call's operands), and what a frame of the callee holds: the closure fn, this as the call binds it (thisValue; undefined where the callee does not read it), the arguments, the environment.
