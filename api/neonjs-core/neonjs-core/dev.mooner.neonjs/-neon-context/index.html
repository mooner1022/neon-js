NeonContext

class NeonContext : AutoCloseable, ContextGate

An isolated JS execution context: one realm (global object + intrinsics), one job queue and its own sandbox limits. Contexts are single-threaded: concurrent use from several threads is serialized by an internal lock.

Evaluates code as an ES module named name (its key for resolving relative imports). Returns the module namespace object once evaluation (including top-level await) has completed. runEventLoop
Link copied to clipboard
fun runEventLoop(timeoutMillis: Long = Long.MAX_VALUE): Boolean

Runs pending jobs and waits for external events — completions of host futures handed to JS (they appear as promises), Atomics.waitAsync wake-ups — until nothing is pending. Returns false if work was still pending after timeoutMillis. Waiting counts against the sandbox's execution-time limit (unless SandboxPolicy.limitsPerTask) and can be stopped with interrupt. While it waits, other threads can use the context.

setExternalJobListener
Link copied to clipboard
fun setExternalJobListener(listener: Runnable?)

Sets what is told each time an external job is posted — a completion of a host future handed to JS, a fetch or WebSocket event, a timer of the web globals, an Atomics.waitAsync wake-up — on the thread that posts it. It should only arrange for runEventLoop with a timeout of 0 to be called on a thread of the host's, which runs the job, so that no thread has to wait in runEventLoop for jobs to come. Null removes it.

setUncaughtErrorHandler
Link copied to clipboard
fun setUncaughtErrorHandler(handler: UncaughtErrorHandler?)

Sets what receives the errors JS leaves uncaught while jobs run, so an event loop can report them and go on: an exception thrown by a task or a microtask (a timer or queueMicrotask callback; that job ends, the others still run) and, at the end of each microtask checkpoint, the promises still rejected without a handler. Without one (the default) such an exception ends the call running the jobs (eval, runEventLoop...) with the rest left queued, and rejections go unreported.
