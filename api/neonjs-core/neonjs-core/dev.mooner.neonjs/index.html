NeonContext

class NeonContext : AutoCloseable, ContextGate

An isolated JS execution context: one realm (global object + intrinsics), one job queue and its own sandbox limits. Contexts are single-threaded: concurrent use from several threads is serialized by an internal lock.

class NeonEngine : AutoCloseable

Entry point: an engine holds shared configuration (execution mode, sandbox policy, host access) and creates isolated NeonContexts. Engines and compiled scripts are thread-safe; contexts are single-threaded.

NeonExtension
Link copied to clipboard
fun interface NeonExtension

An engine module installed into every context of an engine with NeonEngine.Builder.extension (neonjs-node's NodeExtension is one). install gets the context's realm after the built-ins, the console and the web globals; it may define globals and built-in modules (dev.mooner.neonjs.vm.Modules.defineBuiltin). The realm is the engine's internal view: an extension is built against one version of the engine.
