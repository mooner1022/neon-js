class NeonValue

@JvmOverloads
fun await(timeoutMillis: Long = Long.MAX_VALUE): NeonValue

For promises: runs pending jobs until the promise settles and returns its value; throws NeonException if it is rejected. While it depends on external events (host futures, Atomics.waitAsync) waits up to timeoutMillis for them; IllegalStateException if it is still pending after that or once nothing more can settle it.
