ObjectLiteralSite
Link copied to clipboard
class ObjectLiteralSite(val keys: Array<Any>)

An object literal whose properties are all key: value with static, distinct keys (Op.NEW_OBJECT_LITERAL). The object is created after its values are evaluated, directly in its final shape, sharing the key layout with every other object of that site. The layout is cached per empty root shape (shapes belong to one context; code blocks, and so sites, are shared): it is an immutable record published with a single write.

FRAME_POOLING
Link copied to clipboard
@JvmField
val FRAME_POOLING: Boolean

Whether calls of compiled code reuse the frames of returned ones (Agent.framePool): on ART, where allocating and collecting frames took about 45% of a recursive call; not on HotSpot, whose compilers remove the allocation of a frame that does not escape, which a pool defeats (calls of closures 40% slower there). -Dneonjs.framePool=true|false decides instead (the core tests run with it on). A constant: off, the call paths compile as before (HotSpot folds it).
