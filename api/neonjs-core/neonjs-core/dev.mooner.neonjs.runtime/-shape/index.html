Shape

class Shape

Structure token of a PropertyMap, used by property inline caches.

Invariant relied upon by the caches: two maps carrying the same cacheable shape have the same keys in the same slots with the same attribute flags, and their owners have the same prototype and the same Java class. This holds because

  • shared shapes form a transition tree whose root is specific to one (prototype object, owner class) pair, and a map only moves along tree edges when a property is appended;

  • every other structural change (delete, attribute change, prototype change of a non-replayable map, slot compaction) gives the map a fresh unique shape that no other map ever carries.

Transition trees are per prototype object, so they are only touched by the agent that owns that object (contexts are single-threaded) and never shared between contexts; they die with their prototype.

Objects with overridden [[Get]]/[[Set]]/[[HasProperty]] (proxies, host objects, namespaces...) carry UNCACHEABLE.
