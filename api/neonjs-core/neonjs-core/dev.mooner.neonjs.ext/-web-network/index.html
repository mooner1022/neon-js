WebNetwork

object WebNetwork

The network under fetch and WebSocket, for engine modules: neonjs-net's NetExtension gives a realm its transports (with its policy) through install; without them the realm has neither global. The web globals do the standards' part on the context's thread (requests and responses, redirects, header guards, aborts, ready states and events); a transport moves bytes, decides what may be reached, and calls back from any thread.
