TemporalCalendarProvider

interface TemporalCalendarProvider

Service hook for the implementation-defined parts of Temporal that need locale data: non-ISO calendars and the primary identifiers of IANA time zone links. Found with ServiceLoader (META-INF/services); without a provider Temporal supports only the iso8601 calendar and keeps link names as their own primary identifiers.

Implementations are shared by every agent and thread of the JVM, so they must be stateless or thread-safe.
