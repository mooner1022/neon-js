LintOptions

class LintOptions @JvmOverloads constructor(val sourceType: SourceType = SourceType.MODULE, val globals: Globals? = null, val rules: Map<String, RuleSetting> = emptyMap(), val maxDiagnostics: Int = 100, val isCancelled: () -> Boolean = { false }, val extraRules: List<LintRule> = emptyList())

What NeonLint.lint checks and how.

  • globals: the names a script may use without declaring them; null turns the undefined-name and readonly-global-assign rules off (nothing is known of the host's names).

  • rules: a setting for a rule's code; a rule not named keeps its default. Syntax errors cannot be turned off.

  • maxDiagnostics: at most this many diagnostics (the result says when there were more); syntax errors count first.

  • isCancelled: asked as the check goes on; when it says true, the check ends with a result marked cancelled.

  • extraRules: the host's own rules, run after the built-in ones.
